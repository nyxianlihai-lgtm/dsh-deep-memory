# 记忆星河 · 通用可视化框架

只负责「把一批条目画成星系」，**不含任何记忆逻辑**。数据来自你自己。

## 跑起来

```bash
node serve.mjs 8080
```

浏览器打开 http://127.0.0.1:8080

不需要任何依赖，Node 18+ 即可。

## 数据从哪来

默认读同目录的 `data.json`，也可以用参数指向任何地址：

```
http://127.0.0.1:8080/?data=https://your.api/memory
http://127.0.0.1:8080/?data=./my-data.json
```

跨域接口需要对方返回 `Access-Control-Allow-Origin`。

## 数据格式（唯一契约）

```json
{
  "stars": [
    {
      "id": "唯一且稳定",
      "kind": "fact",
      "text": "条目正文",
      "importance": 0.7,
      "activation": 0.9,
      "whenLabel": "昨天（10-30）",
      "scope": "default",
      "status": "current",
      "source": "manual"
    }
  ],
  "counts": { "fact": 3 }
}
```

| 字段 | 作用 |
| --- | --- |
| `id` | 星的稳定标识（同一 id 永远在同一个位置） |
| `kind` | 类型，决定颜色；在 `TYPES` 里加一行就多一种 |
| `text` | 详情面板正文、悬停提示 |
| `importance` | 0–1，**大小** |
| `activation` | 0–1，**亮度**（自己算好，前端不重算） |
| `whenLabel` | 时间说法，原样显示 |
| 其余 | 只用于详情面板 |

## 换成别的领域

改 `brain.html` 里三处即可：

1. **`TYPES`（第 54 行附近）** —— 类型名、中文标签、颜色；
2. **`BLOBS`** —— 形状：若干椭圆 `[cx, cy, rx, ry]` 的并集，换轮廓就换形状；
3. **`SPATIAL` / `GALAXY`** —— 半径、旋臂、厚度等排布参数。

## 规模

- 几百到几千条都流畅；
- 自带 `?demo=1200` / `?demo=3000` 的模拟模式可以压测；
- 超过几千条建议在数据端先聚合（按类型或时间聚成星团）。

## 注意

页面是纯前端，**只读**。不要把它挂在公网——如果数据含隐私，任何人都能看到。
